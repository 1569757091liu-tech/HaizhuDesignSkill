# Taste Skill Adapter

## Role
Establish the visual point of view before implementation.

## Consider when
- the brief is visually ambiguous
- the user wants a distinctive or premium interface
- an existing page feels generic, bland, or AI-generated

## Extract
- visual concept
- typography personality
- color strategy
- spacing rhythm
- surface language
- anti-patterns

## Reject
- generic visual trends without product rationale
- excessive gradients, glass, glow, cards, or rounded containers
- style decisions that conflict with brand/content

## Output
A compact visual direction that downstream UX and implementation adapters can follow.
