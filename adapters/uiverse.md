# Uiverse Adapter

## Role
Provide lightweight UI-element and micro-interaction references.

## Consider when
- a single control needs visual variation
- buttons, toggles, loaders, inputs, checkboxes, or small decorative interactions need exploration

## Extract
- element category
- interaction state
- visual treatment
- CSS complexity

## Reject
Patterns that conflict with the established design language or introduce unnecessary visual noise.

## Output
A concise element-level implementation prompt.
