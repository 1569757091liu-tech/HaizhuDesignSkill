# Aceternity UI Adapter

## Role
Provide high-impact animated React patterns for showcase and marketing surfaces.

## Consider when
- premium landing pages need a focal visual effect
- spotlight, glow, beam, parallax, animated cards, or reveal patterns fit the established visual direction

## Extract
- effect category
- focal hierarchy
- trigger and motion behavior
- customization needs
- performance cost

## Reject
Using multiple signature effects in one viewport without a clear hierarchy.

## Output
A constrained component pattern adapted to the project's design system.
