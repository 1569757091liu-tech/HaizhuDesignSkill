# Impeccable Adapter

## Role
Act as the refinement and quality-review layer.

## Consider when
- reviewing an existing UI
- polishing generated UI
- validating responsive, accessibility, hierarchy, and consistency

## Audit
- hierarchy and scanability
- spacing and density
- typography and contrast
- responsive behavior
- interaction states
- focus and keyboard behavior
- loading, empty, error, and success states
- motion purpose

## Output
Prioritized fixes, ordered by user impact. Do not redesign everything when a targeted correction is sufficient.
