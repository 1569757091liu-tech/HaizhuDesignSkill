# React Bits Adapter

## Role
Find React-native animated component patterns that fit the approved design system.

## Consider when
- the required interaction is naturally component-based
- animated backgrounds, cards, text, cursor effects, or reveals are needed

## Extract
- component category
- interaction model
- animation mechanism
- customization surface
- performance implications

## Reject
Components selected only because they look impressive or because they are popular.

## Output
A project-native component specification and adaptation notes.
