# UI UX Pro Max Adapter

## Role
Solve product UX and interface-pattern decisions.

## Consider when
- designing a new product flow
- choosing page patterns
- resolving information architecture or interaction ambiguity
- creating a design system for a product surface

## Extract
- user goal
- primary/secondary actions
- information hierarchy
- page pattern
- interaction model
- responsive strategy
- accessibility considerations

## Reject
Patterns that look polished but increase cognitive load or hide the primary task.

## Output
A practical UX/UI decision set that can be translated into components and states.
