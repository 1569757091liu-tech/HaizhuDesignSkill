# Design MD Collection Adapter

## Role
Convert design intent into structured implementation specifications.

## Consider when
- a page needs explicit design documentation
- tokens, components, states, or layout rules must be recorded
- implementation needs a stable visual contract

## Extract
- page anatomy
- design tokens
- component specifications
- states
- responsive rules
- interaction rules
- implementation notes

## Output
Structured design guidance that can be consumed by implementation and QA layers.
