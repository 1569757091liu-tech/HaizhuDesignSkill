# HaizhuDesignSkill

> AI-native frontend design engineering skill for distinctive UI/UX and production-ready React implementation.

## What it does

HaizhuDesignSkill combines five design-oriented tools with a selective motion/component reference layer.

### Core tools

- **Taste Skill** — visual direction and anti-slop design judgment
- **Impeccable** — UI audit, refinement, and polish
- **shadcn** — accessible, composable implementation primitives
- **UI UX Pro Max** — UX/UI patterns and design-system reasoning
- **Design MD Collection** — structured design-spec and reference guidance

### Supporting resources

- **Motion Sites** — motion language and interaction inspiration
- **React Bits** — animated React components and backgrounds
- **Uiverse** — UI element patterns
- **Anime.js** — fine-grained JavaScript animation timelines
- **Aceternity UI** — high-impact animated React patterns

## Design philosophy

**Design system first, components second.**

The skill should not blindly assemble fashionable components. It first establishes hierarchy, typography, spacing, color, surface language, interaction rules, and motion principles. External resources are then selected only when they solve a specific UI problem.

## Installation

Copy `SKILL.md` into the skill directory used by your coding agent, or adapt the file to the agent's skill format.

## Resource usage

External resources are treated as references. The skill extracts semantic patterns such as:

- interaction intent
- visual behavior
- motion vocabulary
- component category
- implementation constraints
- accessibility and responsive requirements

It should avoid reproducing large third-party source files or proprietary prompt collections.
