# Workflows

## 1. Landing Page

1. Extract audience, offer, conversion goal, proof, CTA, and brand tone.
2. Establish a single visual thesis with Taste Skill.
3. Validate information hierarchy and section order with UI UX Pro Max.
4. Convert the thesis into tokens and reusable primitives.
5. Use shadcn for structural controls and forms.
6. Select Motion Sites + Aceternity UI or React Bits only for hero/section moments that benefit from motion.
7. Run an Impeccable-style polish pass.

## 2. SaaS Dashboard

Prioritize task completion over visual spectacle.

- UI UX Pro Max: information architecture, navigation, density, states.
- Design MD Collection: structured page/component specification.
- shadcn: tables, dialogs, forms, navigation, menus, feedback.
- Impeccable: hierarchy, spacing, accessibility, responsive audit.
- Motion resources: only for state transitions, feedback, or orientation.

## 3. AI Product

Prioritize conversational clarity, trust, progressive disclosure, and system status.

- Establish input/output hierarchy before decoration.
- Explicitly design loading, streaming, empty, error, retry, and permission states.
- Use React Bits or Aceternity UI only when an animated state communicates meaning.
- Prefer lightweight CSS transitions for ordinary feedback.

## 4. Portfolio / Creative Showcase

This is the exception where atmosphere can be a first-class goal.

- Taste Skill defines the art direction.
- Motion Sites provides motion vocabulary.
- React Bits and Aceternity UI provide implementation candidates.
- Anime.js is reserved for choreography that needs timeline control.
- Keep accessibility and reduced-motion behavior intact.

## 5. Redesign Existing UI

1. Preserve existing product semantics and content unless asked otherwise.
2. Audit the current UI before replacing components.
3. Identify the highest-impact 20% of visual problems.
4. Establish a new token and component language.
5. Refactor repeated patterns into shared primitives.
6. Add motion only after the static hierarchy is correct.
7. Compare desktop, tablet, and mobile states before completion.
