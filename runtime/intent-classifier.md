# Intent Classifier

Classify the request across six dimensions. Multiple labels may apply.

## Dimensions

### Surface
- landing-page
- dashboard
- application
- form-flow
- marketing-section
- portfolio
- documentation
- navigation
- component
- redesign

### Primary problem
- visual-direction
- ux-flow
- information-architecture
- component-selection
- motion
- responsive
- accessibility
- polish
- implementation

### User intent
- discover
- evaluate
- convert
- create
- edit
- monitor
- compare
- navigate

### Visual intensity
- restrained
- expressive
- premium
- experimental

### Motion intensity
- none
- subtle
- interactive
- cinematic

### Technical context
Capture framework, styling system, existing component library, constraints, and whether new dependencies are acceptable.

## Classification rule
When uncertain, prefer conservative labels. Do not infer cinematic motion from words such as "modern" or "premium" alone.
